# Smart Public Transport Tracker Database

## Database Management System

- MySQL
- XAMPP
- phpMyAdmin

## Files

- `schema.sql` - Creates the database and tables.
- `sample_data.sql` - Inserts sample records.
- `queries.sql` - Demonstrates SQL queries used by the application.
- `indexes.sql` - Creates indexes for performance optimization.

## Features

- Normalized relational database
- Primary and foreign keys
- Sample transport data
- Join queries
- Indexes for improved performance
